# Fluffy Tutorials

A step-by-step path through Fluffy. Each tutorial is a small, self-contained app you can compile and run, and each one introduces one new idea.

## New to Fluffy? Start here

Fluffy builds desktop apps out of three simple ideas:

- A **window** is the frame you see on screen.
- **Widgets** are the things inside it — labels, buttons, text fields, sliders and so on. The window owns them; you never delete them yourself.
- You **place** each widget with a rectangle (a position and a size) and **listen** to it with a small callback function.

If those words feel unfamiliar, that is fine — Tutorial 1 explains each one as it comes up. You will not need to look anything up elsewhere.

## Suggested order

1. **[Hello Fluffy](01-hello-fluffy.md)** — open a window, add a label and a button, and react to a click.
2. **[Counter](02-counter.md)** — keep a value in your program and update a label when a button is pressed.
3. **[Input Form](03-input-form.md)** — read what the user typed in a text field and respond.
4. **[Layouts](04-layouts.md)** — let Fluffy arrange your widgets instead of placing them by hand.
5. **[Icons and Themes](05-icons-and-themes.md)** — add built-in icons and switch between light and dark looks.
6. **[YAML UI](06-yaml-ui.md)** — describe a whole window in a text file instead of C++.
7. **[Dialogs](07-dialogs.md)** — ask the user to confirm something.
8. **[Data Widgets](08-data-widgets.md)** — show lists, tables, tabs and progress.
9. **[WebView](09-webview.md)** — display web content inside a window.
10. **[Multiwindow](10-multiwindow.md)** — run more than one window at the same time.
11. **[Custom Widget](11-custom-widget.md)** — draw and handle input for a widget of your own.

Work through the list in order if you are new. Each tutorial takes about 5–15 minutes, and by the end you will know enough to build small Fluffy apps on your own.
